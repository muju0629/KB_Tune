# 1~8주 모델 비교 발표 자료

## 01_model_ranking_8week

- 질문: 같은 카드·캘린더 피처를 주면 어떤 점예측 모델이 가장 정확한가
- 결론: 8주 WAPE는 LightGBM 38.0%, Ridge 38.6%, Random Forest 39.2%, Renewal Bayesian 41.8%
- 발표 문장: “점예측은 LightGBM, 발생확률과 구간은 Bayesian으로 역할을 분리했습니다.”

## 02_learning_curve_1_to_8

- 질문: 개인 이력이 1주에서 8주로 늘 때 모델별 성능은 어떻게 변하는가
- 결론: 글로벌 회귀는 첫 주부터 인구 패턴을 사용해 높고 평탄하다. 최근 평균만 가파르게 상승한다.
- 주의: KB Tune 모델의 급격한 상승을 주장하는 근거로 사용하면 안 된다.
- 발표 문장: “콜드스타트는 인구 모델로 해결하고, 8주 동안은 개인화와 확률 보정을 진행합니다.”

모든 수치는 합성 데이터 구조 검증 결과이며 실사용자 정확도가 아니다.
